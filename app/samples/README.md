# 샘플 파일

기능 확인용 **가상 자료**입니다. 회사명·인물·연락처·금액은 모두 지어낸 값이고 실제 기관 자료가 아닙니다.
`tools/make_samples.py`로 다시 만들 수 있습니다.

| 파일 | 설명 |
| --- | --- |
| `handover_sample.md` / `.docx` / `.hwpx` / `.pdf` | 같은 내용을 4가지 형식으로 만든 인수인계서 초안. 2단계 점검에서 빈틈이 드러나도록 일부 항목(예외 상황·검증 방법·진행 중 현안·근거 규정)을 일부러 비워 두었습니다. |
| `regulation/kepco_basic_supply_terms.pdf` | 3단계 기본 규정 예시(한국전력공사 기본공급약관). 출처·해시는 `regulation/SOURCE.md`에 적었습니다. |

`.hwp`(구형 바이너리)는 한글에서 저장한 파일이 필요해 저장소에 넣지 않았습니다.
파서는 실제 한글 파일(5.0.3.0)로 확인했고, `HWP_FIXTURE=<파일 경로>` 환경변수를 주면 테스트가 그 파일로 실행됩니다.
